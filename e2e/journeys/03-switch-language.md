# Switch language

Precondition: install the clean fixture flavor and use English as the initial app language. Start with cleared app data.

| Step | Expected UI |
| --- | --- |
| Launch the app. | Boards appears. |
| Open Settings. | Language choices include Bahasa Indonesia. |
| Select Bahasa Indonesia. | The board list appears, with Boards translated as Papan. |

Flow: `e2e/maestro/03-switch-language.yaml`.
