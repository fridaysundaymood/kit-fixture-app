# Add a task

Precondition: install either fixture flavor and use English as the initial app language. Start with cleared app data.

| Step | Expected UI |
| --- | --- |
| Launch the app. | Boards appears. |
| Open General. | The board offers Add task. |
| Choose Add task. | The Task title field appears. |
| Enter `Prepare fixture` and choose Save. | The General board displays `Prepare fixture`. |

Flow: `e2e/maestro/02-add-task.yaml`.
